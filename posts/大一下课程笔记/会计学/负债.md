# CH5 负债 知识点速通

## 一、负债概述

- **定义**：过去交易形成的现时义务，预期会导致经济利益流出企业。
    
- **分类**：
    
    - 流动负债：偿还期≤1年，金额小
        
    - 非流动负债：偿还期>1年，金额大
        

---

## 二、短期借款

### 会计分录

markdown

1. 借入本金：
   借：银行存款
   贷：短期借款
2. 期末计提利息：
   借：财务费用
   贷：应付利息
3. 还本付息：
   借：短期借款
       应付利息
   贷：银行存款

### 示例：A公司借款100,000元，年利率6%，期限3个月

markdown

7.1 借入：
   借：银行存款 100,000
   贷：短期借款 100,000
7.31/8.31/9.30 计提利息（500元/月）：
   借：财务费用 500
   贷：应付利息 500
10.1 还本付息：
   借：短期借款 100,000
       应付利息 1,500
   贷：银行存款 101,500

## 三、应付及预收账款

### 1. 应付票据

markdown

签发时：
   借：原材料/在途物资
       应交税费-应交增值税（进项税额）
   贷：应付票据
到期支付：
   借：应付票据
   贷：银行存款
拒付：
   借：应付票据
   贷：应付账款

### 2. 应付账款

markdown

货物与账单同到：
   借：原材料
       应交税费-应交增值税（进项税额）
   贷：应付账款
货物先到，账单未到（月末暂估）：
   借：原材料
   贷：应付账款
下月初红字冲回：
   借：原材料（红字）
   贷：应付账款（红字）
无法支付：
   借：应付账款
   贷：营业外收入

### 3. 预收账款

markdown

预收时：
   借：银行存款
   贷：预收账款
交付商品时：
   借：预收账款
   贷：主营业务收入
       应交税费-应交增值税（销项税额）
补收余款：
   借：银行存款
   贷：预收账款

## 四、应交税费

### 1. 增值税（一般纳税人）

markdown

购进可抵扣：
   借：原材料
       应交税费-应交增值税（进项税额）
   贷：银行存款
进项税额转出（用于福利、非正常损失）：
   借：待处理财产损溢/管理费用
   贷：应交税费-应交增值税（进项税额转出）
销售商品：
   借：银行存款
   贷：主营业务收入
       应交税费-应交增值税（销项税额）
视同销售（如对外投资）：
   借：长期股权投资
   贷：主营业务收入
       应交税费-应交增值税（销项税额）

### 2. 消费税

markdown

计提：
   借：税金及附加
   贷：应交税费-应交消费税
自产产品用于在建工程：
   借：在建工程
   贷：库存商品
       应交税费-应交消费税

### 3. 城市维护建设税 & 教育费附加

markdown

计提：
   借：税金及附加
   贷：应交税费-应交城市维护建设税
       应交税费-应交教育费附加

## 五、应付职工薪酬

markdown

计提工资：
   借：生产成本/管理费用/在建工程/销售费用
   贷：应付职工薪酬-职工工资
计提社保、公积金、工会经费等：
   借：生产成本/管理费用等
   贷：应付职工薪酬-住房公积金
        -医疗保险费
        -工会经费
        -职工教育经费

## 七、非流动负债

### 1. 长期借款

markdown

借入：
   借：银行存款
   贷：长期借款-本金
计提利息（资本化）：
   借：在建工程
   贷：长期借款-应计利息（或应付利息）
归还：
   借：长期借款-本金
   贷：银行存款

### 2. 应付债券（按面值发行）

markdown

发行：
   借：银行存款
   贷：应付债券-面值
计提利息：
   借：在建工程/财务费用
   贷：应付利息
支付利息：
   借：应付利息
   贷：银行存款
到期还本：
   借：应付债券-面值
   贷：银行存款

### 3. 预计负债

markdown

产品质量保证：
   借：销售费用
   贷：预计负债
未决诉讼：
   借：营业外支出
   贷：预计负债
实际发生维修费用：
   借：预计负债
   贷：银行存款
